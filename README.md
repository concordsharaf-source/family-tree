# شجرة العائلة

تطبيق PWA عربي (RTL) لإدارة شجرة العائلة، يعمل دون اتصال ويحفظ البيانات والصور محليًا على الجهاز عبر IndexedDB (Dexie). لا يوجد خادم ولا حسابات ولا إرسال بيانات.

- **التقنية:** React + TypeScript + Vite + Dexie + vite-plugin-pwa
- **الخطة الكاملة:** [plan.md](./plan.md)
- **نتائج المشروع:** [TODO.md](./TODO.md)

## التشغيل محليًا

```bash
pnpm install
pnpm dev        # http://localhost:3000
pnpm test       # اختبارات Vitest (13 اختبارًا)
pnpm build      # بناء الإنتاج في dist/
pnpm preview    # معاينة بناء الإنتاج
```

## الاختبارات

| الملف | التغطية |
| --- | --- |
| `tests/relationships.test.ts` | محرك القرابة: الحفيد، الجد، العم، الأخ، منع الدورات والتكرار |
| `tests/backup.test.ts` | التحقق من ملفات النسخ الاحتياطي وبناء الاسم الكامل |
| `tests/app-boot.test.tsx` | **إقلاع التطبيق فعليًا** في jsdom مع IndexedDB وهمي: رسم شاشة البداية، والعائلة المحفوظة بعد إعادة التشغيل، وسلامة مسار تسجيل الـService Worker |

> اختبار الإقلاع يمنع تكرار مشكلة «الصفحة البيضاء»: أي انهيار وقت التشغيل أو خلل في
> مسار الأصول يُسقط الاختبار.

## النشر

المسار الأساسي (base) يُضبط عبر متغير البيئة `VITE_BASE_PATH`:

| الاستضافة | المسار الأساسي | الإعداد |
| --- | --- | --- |
| Vercel / أي نطاق جذري | `/` (الافتراضي) | `vercel.json` مُرفق، لا حاجة لأي متغير |
| GitHub Pages (مستودع فرعي) | `/<اسم-المستودع>/` | يُكتشف تلقائيًا داخل GitHub Actions |
| تجاوز صريح | أي مسار | `VITE_BASE_PATH=/path/ pnpm build` |

> ⚠️ إذا نُشر التطبيق على نطاق جذري دون ضبط المسار الأساسي، ستُطلب الأصول من مسار
> خاطئ (`/family-tree/assets/...`) وتظهر **صفحة بيضاء**. تأكّد دائمًا من مطابقة
> `VITE_BASE_PATH` مع مكان نشر الأصول.

### Vercel

1. اربط المستودع بمشروع Vercel (Framework Preset: **Vite**).
2. اترك إعدادات البناء الافتراضية — `vercel.json` يحدّد البناء والخرج وإعادة
   كتابة المسارات (SPA) وترويسات عدم تخزين `sw.js` كي تُطبَّق التحديثات فورًا.
3. بعد الدمج في `main` يُعاد النشر تلقائيًا.

### GitHub Pages

يُبنى ويُنشر تلقائيًا عند كل دفع إلى `main` عبر
[`.github/workflows/deploy-pages.yml`](.github/workflows/deploy-pages.yml)
مع `VITE_BASE_PATH=/family-tree/`.

## الخصوصية

كل البيانات (الأفراد، العلاقات، الزوجية، الصور المصغّرة، الإعدادات) تبقى على جهاز
المستخدم في IndexedDB، مع تصدير/استعادة نسخة احتياطية بصيغة JSON.
